# environment

Do not assume you know which programs exist on this computer or how they behave here, even familiar ones such as git, sudo or a package manager. `~/environment.md` says what exists and how to use it here. Read the part you need before searching the machine, trying something from memory, installing an alternative or asking me, then check only what the work needs. What you observe now beats what the file says.

Keep the file true. Record what a future agent could use beyond one project: a tool, a service, an access, a useful command, and their limits. When something is new, moved or gone, correct the existing entry instead of adding one. Describe only the present: no dates, no history, no record of who did what.
